# Legacy Studio Scaffold

This folder is a leftover standalone Studio scaffold from an earlier setup.

The canonical Sanity setup for this project now lives at the repository root:

- `sanity.config.ts`
- `sanity.cli.ts`
- `schemaTypes/`

For day-to-day work, use the root project instead:

- `npm run dev` and open `/studio`
- or `npm run studio` from the repository root
